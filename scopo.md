propósito principal:
    -um rpg de turno de brawser em que: 
    ao encontrar um inimigo novo, o jogador escolhe o nome e aparência

Requisitos Funcionais:
    -RF001: sistema de upload de imagens e texto para cada skill e personagem de cada conta
    -RF002:imagens e nomes aparecerem nos espaços antes vazios
    -RF003: se tipo de inimigo repetir as imagens e texto antes subidos se repetem
    -RF004: IA para os inimigos usarem suas skills
    -RF005: sistema de contas(imagens subidas não se carregam entre contas)

    -RF006: ordem de turno
    -RF007: sistema de runs(poder voltar os uploads ao padrão)

Requisitos Não Funcionais:
    -RNF001(software): código em ambiente Node.js utilizando o framework Express e Drizzle
    -RNF002():

    -UC001:criar conta

    -UC003:fazer upload de um novo inimigo
        -
    -UC004:começar uma run
        -
    -UC005:continuar uma run
        -
